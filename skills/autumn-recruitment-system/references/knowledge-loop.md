# 原始问题、Q&A、练习、能力与简历

## 四类对象不可混写

### 原始问题

只保存真实笔试、真实面试或模拟面试中实际出现的具体问法，保留来源、岗位、轮次、场次、原始措辞、追问和当次表现。

当次作答表现：未作答、提示后完成、独立完成、稳定深入。后续答案进步不改写现场。

### Q&A

表示多个原始问法背后的共性核心问题，保存考察本质、回答主线、个人证据、常见追问和风险边界。

- 回答成熟度衡量答案内容质量。
- 口头熟练度衡量现场表达熟练程度。
- 只有考察意图与回答主干一致时才合并。

### 能力练习

对话 Case、专项练习、知识自测和项目演练只写练习库，不进入原始问题库。正文保留 Case、初答、关键缺层、提示、修正回答、未验证部分和下一轮练习。

### 能力图谱

能力节点记录理解程度与独立应用程度，关联练习、Q&A、原始问题和经历素材。每天的能力缺口必须来自这里。

## 证据更新规则

- 教练讲过但用户未作答：不算掌握。
- 提示后完成：最多“提示下完成”。
- 独立完成相似新 Case：才升为“独立完成”。
- 多次跨场景稳定应用，或真实项目/笔面试验证：才升为“稳定迁移”。
- 单次失误只标记待验证；重复失败或明确事实冲突才降级。
- 每次变更写明证据来源和最近验证日期。

## 对话 Case

1. 先判断本次是否真的是练习；讲解、闲聊或只看示例不写练习记录。
2. 记录初答、提示程度、练习结果和未验证部分。
3. 关联最少且确切的能力节点。
4. 依据证据更新能力节点，不把模型提供的方法算作用户掌握。
5. 模拟面试中实际问过的问题可进入原始问题库；普通 Case 不进入。

## 每日模拟面试沉淀

1. 每场每日模拟形成一条能力练习记录，记录题目范围、初答、追问、提示程度、修正回答、结论和待复测项。
2. 模拟中实际问过的每个具体问题，以“模拟面试”为来源写入原始问题库；不要把整场模拟只当普通 Case，也不要把未实际提问的外部面经写入。
3. 只有考察意图和回答主干一致时，才关联或更新 Q&A；不能为每个措辞都新建 Q&A。
4. 能力图谱依据当次作答表现更新证据、最近验证日期和下一步行动；单次提示后完成最多记为“提示下完成”。
5. 若当天模拟未完成，保留待办，不伪造练习记录、原始问题或能力更新。

## 面试复盘

按“现场事实 → 原始问题 → Q&A → 经历素材 → 能力图谱”处理：

- 先忠实恢复原话、追问、回答和反馈。
- 再判断哪些只是本场原始问法，哪些可关联或新建 Q&A。
- 只有用户真实经历可进入经历素材。
- 能力变化必须引用本场表现；不要用润色后的答案倒推现场表现。

## 简历优化

- 分别维护 AI 产品经理和数据分析版本。
- 只使用经历素材、可验证结果和真实面试反馈。
- 不进行岗位推荐或匹配评分。
- 修改前检查事实边界、数字口径和个人贡献；不凭空补充项目结果。
